# Nexus human-output protocol\n\n## Goal\nMinimize time and cognitive load between a machine result and human understanding without concealing uncertainty.\n\n## Default output sequence\n1. **Status signal** — plain status (SUCCESS, SIMULATED, PENDING, FAILED, UNVERIFIED).\n2. **Result** — the primary outcome in one short sentence.\n3. **Object/operation** — object ID and command.\n4. **Source** — user input, live source, adapter, or simulation.\n5. **Timestamp** — time of result generation/observation.\n6. **Verification** — evidence and limits. Never imply physical verification without evidence.\n7. **Next action** — one clear recommended action, or indicate none.\n\nUse short lines, direct language, plain text readable on screen, and expand details only on demand. Use accessible status text in addition to visual indicators. Errors should state the cause and recovery step. Do not present simulated results as measurements or executed actions.\n
